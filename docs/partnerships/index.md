# Industry Partnerships

Part of the [Biola-X](../index.md) initiative.

Industry partnerships are the multi-year relationships behind the projects. A
partner might sponsor a capstone team, host a summer intern, mentor students,
provide equipment, or hire graduates — often several of these over time. This
section tracks each partner organization and where the relationship stands.

## Add a partner

1. Copy an existing file in `docs/partnerships/` (they all follow the same
   four-card layout: **Partnership Focus**, **Point of Contact**,
   **Projects & Engagements**, **Opportunities & Next Steps**).
2. Fill it in and set the status pill (`active` / `prospective` / `paused`).
3. Add a card to the grid above and a nav line under **Industry Partnerships**
   in `mkdocs.yml`.
4. Commit and push.
