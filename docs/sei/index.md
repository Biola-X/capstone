# Summer Engineering Internships (SEI)

Part of the [Biola-X](../index.md) initiative.

The Summer Engineering Internship program places one or two students on a focused
engineering problem for 8–10 weeks over the summer, working with a faculty advisor
and — where there is one — an industry or community partner. Each internship ends
with a working deliverable and a short technical report.

This page is an archive of **completed SEI projects**.

## Add a completed project

1. Copy one of the `-` card blocks above.
2. Update the icon, title, status pill (`completed` / `active` / `paused`),
   summary, partner, and deliverable.
3. Keep the cards in reverse-chronological order (newest first).
4. Commit and push — the site rebuilds automatically.

For a longer write-up, create a file at `docs/sei/<project-slug>.md`, link the
card title to it, and add a nav line under **Summer Engineering Internships** in
`mkdocs.yml`.
